# 离线教程学习设计

## 学习目标

笔记不是给视频套同一张模板，而是帮助读者：

1. 先看到作者真实说过、做过什么。
2. 理解当前片段承担的是定位、方法、决策、过程、案例、提醒还是结论。
3. 只在原视频确实给出可迁移步骤时，帮助读者应用。

## 自适应章节结构

新任务使用 `learning_design_version: "adaptive-blocks-v1"`。

每章先选择一个 `chapter_role`：

- `overview`：说明目标、范围和背景。
- `method`：解释一种明确方法。
- `decision`：给出选择依据或取舍。
- `process`：复原连续操作或制作过程。
- `case`：分析作者完整案例。
- `warning`：说明限制、误区或风险。
- `conclusion`：汇总结果和作者结论。

每章必须包含：

- `chapter_summary`：一句白话说明本章真正解决什么。
- `author_statement`：页面显示的“作者原话”，只用一句话准确整理作者核心原意。
- `plain_rewrite`：紧跟作者原话，用通俗、顺畅的语言解释作者想表达的内容。
- `source_quotes`：内部逐字证据，至少一条并带时间戳；不得用概括替代作者原话证据。
- `content_blocks`：只选择当前章节需要的内容块。
- `evidence`：与本章语义一致的截图和时间戳。

顶层 `ai_advice_enabled` 默认开启，用户可以关闭。开启时每章还必须包含独立的
`ai_advice`；关闭时不得生成该字段。

## 内容块路由

按视频事实选择内容块并保持自然阅读顺序：

- `scope_facts`：数量、范围、状态等具体事实。
- `case_reconstruction`：情境、过程和结果完整的作者案例。
- `explanation`：把作者做法翻译成读者能理解的因果。
- `process`：原视频明确展示的连续步骤。
- `comparison`：作者明确比较的方案或取舍。
- `limitations`：缺口、适用边界和未完成部分。
- `takeaway`：从充足证据中提炼出的一个方法。
- `application`：作者的方法存在明确迁移步骤时才输出。
- `observation`：读者容易只看表面动作时揭示观察重点。
- `summary`：当前章节的最终结论。

没有明确迁移步骤时省略 `application`，不得为了结构完整强行生成“直接套用”。
没有完整案例时省略 `case_reconstruction`；概览章可以只包含范围事实、解释和总结。

## 作者表达、AI 建议与事实精度

- `author_statement` 只保留一句作者核心原意，可以去除口头禅、重复和语病，但不能改变作者观点。
- `plain_rewrite` 只优化表达，不负责偷偷纠正作者的事实错误。
- `source_quotes[].text` 必须能在转写片段中找到，不进行润色、补词或合并改写；它只作为内部证据。
- 数量词、否定、范围、前提和不确定性必须忠实保留，例如原话是“四五只”就不得改成“五只”。
- `ai_advice` 与作者表达分区呈现，先判断“正确”“部分正确”“错误”或“证据不足”，再提供依据和指导。
- 作者观点正确时建议保持简短；只有观点错误、不完整或可能误导时才详细展开。
- 原视频信息不完整时使用 `limitations` 明确缺口，禁止猜测补齐。
- 标题、原话、内容块、截图和时间戳必须属于同一语义片段。

作者表达、通俗改写和 AI 建议在同一次结构化重写中生成，只提供当前章节所需证据，
不得为了生成 AI 建议再次提交完整视频转写。

## 语义边界

- 开始新话题、新案例、新操作目标或新结论时才切章。
- 同一案例的动作、原因、结果不得拆散到不同章节。
- 章节数量由内容决定，最多 40 章；超过后重新检查是否切得过碎。
- 证据包的章节边界必须与最终章节对齐；若最终重新切章，重新映射转写与截图证据。

## 完全离线与阅读体验

- 交付目录至少包含 `index.html`、本地资源和结构化章节 JSON。
- CSS 与 JavaScript 内联或本地化，不使用 CDN、在线字体或远程组件库。
- 长页提供章节目录、当前章节提示和阅读进度；移动端不产生横向滚动。
- 证据图使用 `loading="lazy"`、`decoding="async"` 和描述性 `alt`。
- 页面不要求答题、输入命令、提交答案或等待 GPT 评价，不评分。

## 旧版兼容

已有 `b-c-v1` 文件继续按 B 统一骨架渲染，C 观察模块仍按需启用。
旧版的作者原例、真正精髓和直接应用字段只用于兼容，不得作为新任务的固定要求。

## 验收

- 随机抽查至少 3 章，确认标题、作者原话、通俗改写、截图和时间戳语义一致。
- 作者原话只有一句，页面不显示该句的时间戳。
- 每一条 `source_quotes` 都能在对应转写时间段中定位。
- AI 建议默认显示；关闭后 JSON 与页面均不包含该模块。
- 章节不需要的内容块没有出现在页面中。
- 桌面和 390px 宽度均无横向溢出，控制台错误为 0。
- 断网时可阅读、展开、导航，远程样式、脚本、字体请求为 0。
- 不存在答题、评分、答案输入和学习记录模块。
