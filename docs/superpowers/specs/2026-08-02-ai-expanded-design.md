# AI Expanded 典藏学习笔记设计

## 目标

在已验收的 `source-faithful.md` 基础上，生成一份独立、可收藏、可直接学习的 `ai-expanded.md`。

- 面向教程与教学视频。
- 用大白话重组、筛选、纠正并适度扩展内容。
- 让读者理解并能使用知识，而非阅读视频摘要或核查报告。
- 最终只交付 Markdown；不生成 HTML。

## 双产物边界

| 产物 | 用途 | 读者可见内容 |
| --- | --- | --- |
| `source-faithful.md` | 忠实记录原视频 | 时间戳、视频操作、实际讲解内容 |
| `ai-expanded.md` | 独立典藏学习笔记 | 重组后的知识、通俗解释、必要示例与练习 |

`source-faithful.md` 必须冻结。扩展阶段不得覆盖、修改或删除它。

`ai-expanded.md` 不显示时间戳、来源标签、核查过程、原视频口语或内部审计信息。它不是视频注释，而是一份以视频为起点的全新学习材料。

## 用户交互

用户只用自然语言表达目标，无需理解内部配置名。例如：

- “让我快速看懂这个视频。”
- “我完全不会，带我学到能自己做出来。”
- “我有基础，重点纠正并扩展实际用法。”
- “重点讲和弦选择；自动核查；不要讲混音。”

如果用户未补充要求，默认目标为：**讲明白，并让我能马上使用，不啰嗦。**

系统从自然语言中提取以下内部选项：

| 用户意图 | 内部含义 |
| --- | --- |
| 快速看懂 | 精简解释，只保留必要例子 |
| 学到能用 | 增加判断条件、最小示例和操作检查点 |
| 深入掌握 | 增加边界、变体、迁移练习和知识连接 |
| 完全不会 | 首次术语解释和更多完整示例 |
| 有基础 | 跳过基础定义，保留边界和进阶用法 |
| 自动核查 | 仅核查高风险、明显矛盾或时效性内容 |
| 重点核查 X | 在自动核查之外强制检查 X |
| 不要联网核查 | 关闭联网核查 |

用户的明确指令优先于默认策略。

## 生成流程

```text
source-faithful.md + 内部证据 + 自然语言要求
                    ↓
            重塑规划（内部）
                    ↓
       必要时的最小联网核查（内部）
                    ↓
              最终 Markdown 写作
                    ↓
              ai-expanded.md
```

1. **重塑规划**：提取知识点、操作、方法论和作者偏好；删除视频口语、重复和低价值内容；按知识类型决定解释方式。
2. **最小核查**：默认不做全量事实审查。仅检查高风险、明显可疑、可能过时或用户点名的内容。作者偏好与创作取舍不当作客观错误纠正。
3. **最终写作**：把规划转为一份干净的独立学习笔记。模型调用固定为规划和写作两次，不增加循环改写。

联网失败时仍可生成笔记，但不得把相关补充写成已验证结论。外部查询记录只供内部审计，不进入最终 Markdown。

## 内容结构

结构随内容变化，禁止为凑模板输出空栏目或重复段落。

```text
30 秒掌握

学习单元（按概念、方法论、实操或事实信息分型）

立即应用（仅 1–3 个真正有价值的练习、自测或迁移任务）
```

不同知识类型的写法：

| 类型 | 必须回答 | 按需补充 |
| --- | --- | --- |
| 概念 | 是什么、为什么重要 | 大白话、类比、最小例子、边界 |
| 方法论 | 何时用、如何判断、何时别用 | 对比例子、可复用流程 |
| 软件/实操 | 目标、实际步骤、关键检查点 | 易错点、通用操作建议 |
| 事实/清单 | 必要结论 | 简表或最短记忆法 |

费曼式解释只用于抽象或关键概念。新操作优先呈现完整示例和检查点，再给少量独立练习；不对每个章节强制出题或类比。

## 质量门槛

1. **减负**：删除寒暄、重复、装饰性栏目和无助理解的扩展；结论优先。
2. **通俗**：术语首次出现必须解释；不得以另一套术语替换原术语；类比必须避免误导。
3. **可用**：方法必须给出适用条件；软件操作不得捏造按钮、参数或步骤。
4. **完整**：重写后保留学习所必需的前提、判断逻辑和关键步骤，而非机械保留全部口语。
5. **适度扩展**：每一处扩展必须服务当前视频主题；不能凭空变成无关课程。
6. **篇幅**：提高理解密度，不以增加段落数作为扩展；同一个结论只保留一次。
7. **边界**：`ai-expanded.md` 不含时间戳、来源标记、核查报告或 HTML。

## 实现边界

`ai-expanded` 是独立二阶段流程，不重新引入会污染主流程的 `note.mode` 分支。

复用现有 `evidence_pack`、章节和 Markdown 工具，但不重复下载、转写、逐帧分析或 HTML 渲染。建议新增独立的准备、校验和 Markdown 写入命令。

自动校验只负责结构性规则：

- `source-faithful.md` 未被改动。
- 输出仅为 `ai-expanded.md`，没有 HTML 交付。
- 没有空栏目、重复标题或无内容区块。
- 纠错和联网补充的内部审计记录存在时格式合法。

语义质量由“重塑规划 + 最终写作”的提示词与人工验收保证，不伪造可自动证明的事实正确性指标。

## 非目标

- 不把 AI 扩展写成带时间戳的原视频笔记。
- 不输出面向读者的引用、来源清单或核查报告。
- 不生成 HTML、题库、长期学习计划、账号系统或复杂 UI。
- 不对所有教程内容进行昂贵的联网逐条审查。
